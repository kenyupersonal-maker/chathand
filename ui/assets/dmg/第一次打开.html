第一次打开 ChatHand

ChatHand 还没做苹果公证，macOS 第一次会拦一下。复制下面这行命令，到终端粘贴、回车，ChatHand 会自己打开。以后直接从「应用程序」打开就行。

这是你自己手动装的路；让 ChatGPT 装，它照 App 里的 codex/INSTALL.md。

推荐

复制命令，到终端粘贴、回车

A=/Applications/ChatHand.app; [ -d "$A" ] || { S=$(sh -c 'ls -d /Volumes/ChatHand*/ChatHand.app' 2>/dev/null | head -n1); [ -n "$S" ] && ditto "$S" "$A"; }; if [ -d "$A" ]; then xattr -dr com.apple.quarantine "$A" 2>/dev/null; open "$A"; else echo "没找到 ChatHand：先双击打开安装盘，再粘贴一次。"; fi

这行命令只做三件事：没装的话，从安装盘装进「应用程序」；去掉 ChatHand 的下载标记；打开它。不改系统设置。

  1. 1点上面的「复制命令」
  2. 2打开「终端」：按⌘空格，输入「终端」，再按回车
  3. 3在终端里按⌘V粘贴，再按回车。ChatHand 会自己打开。

先把 ChatHand 拖进「应用程序」。没拖也没关系，这行命令会自己从安装盘装进去。

已经双击过、被拦了？没关系，照样做这一步。

⌘ 空格打不开搜索？从 启动台 → 其他 → 终端 打开。

1双击 ChatHand，点「完成」
2在设置里点「仍要打开」
打开「隐私与安全性」
3再点「仍要打开」，按指纹

第 2 步没看到「仍要打开」？它只在你试过打开后约一小时内出现，回到第 1 步再双击一次。macOS 14：按住 Control 点 ChatHand，选「打开」。

公司或学校的 Mac 上一直看不到「仍要打开」，可能是管理员关掉了，需要找管理员。
