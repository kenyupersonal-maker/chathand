# 安装 ChatHand

适用于 Apple 芯片（M 系列）的 Mac，macOS 14 或更新。要准备什么，见 [README](../README.zh-CN.md#用之前要准备的)。

[English](INSTALL.en.md)

先获取当前版本的 ChatHand macOS 安装盘。想核对文件的话，在终端运行下面这行，结果应和发布页写的 SHA-256 一致：

```sh
shasum -a 256 ~/Downloads/ChatHand*.dmg
```

## 1. 交给 ChatGPT（推荐）

要有 ChatGPT 桌面版。双击 DMG 里的「让 ChatGPT 来装」，浏览器问要不要打开 ChatGPT 时点「打开」。ChatGPT 填好这句话后按回车，它会自动转到「工作」完成安装。

```text
进入 Work 模式，帮我安装 ChatHand 并连上 ChatGPT。安装包在「下载」文件夹里，步骤写在安装包里的 ChatHand.app/Contents/Resources/codex/INSTALL.md。
```

ChatGPT 会把 ChatHand 装进「应用程序」、去掉下载标记（这样 macOS 不会再拦）、打开它，再自己创建或复用 ChatGPT 应用、连上、设为「允许使用所有工具」，在网页版开启所需开发者模式，并新开对话完成真实测试。安装话已经包含这些步骤，不另等你确认。ChatHand 窗口里会显示进度；电脑密码或 Touch ID、登录密码和验证码由你完成，平台确实无法操作时只请你完成卡住的一步后继续。Chrome 扩展和隐私权限仍照原流程。

- 没自动转到「工作」：点「在 Work 中继续」；已经留在聊天里了，就点上方的「工作」，再发一次。
- 没有 ChatGPT 桌面版，或者里面没有「工作」：走第 2 节，自己装。

## 2. 自己装

1. 双击安装盘里的「第一次打开」，点「复制命令」。
2. 打开「终端」：按 ⌘空格，输入「终端」，再按回车。
3. 在终端里按 ⌘V 粘贴，再按回车。ChatHand 会自己打开。

这行命令只做三件事：没装的话，从安装盘装进「应用程序」；去掉 ChatHand 的下载标记；打开它。不改系统设置。以后直接从「应用程序」打开就行。

- 看到「没找到 ChatHand」：先双击打开安装盘，再粘贴一次。
- 安装盘已经推出、找不到「第一次打开」：去「下载」里重新双击 DMG。
- 已经双击过 ChatHand、被拦了，或者点了「移到废纸篓」：照样做上面三步，命令会重新装好。

### 终端用不了：在系统设置里放行

先把 ChatHand 拖进「应用程序」。ChatHand 用自己的证书签名，还没做苹果公证，所以 macOS 第一次会拦一下。

**macOS 15 及以后**


以下只供用户选择手动双击安装时参考；AI 一句话安装不走手动放行，先按本文「AI 安装的首次运行顺序」清并核验下载标记。

1. 在「应用程序」里双击 ChatHand。系统提示无法验证，点「完成」。不要点「移到废纸篓」。
2. 打开「系统设置 › 隐私与安全性」，往下翻到「安全性」，在 ChatHand 那一行点「仍要打开」。
3. 在弹出的窗口里再点「仍要打开」，输入电脑密码或用触控 ID。

「仍要打开」只在你试过打开后大约一小时内出现。没看到就回到第 1 步再双击一次。

**macOS 14**

在「应用程序」里按住 Control 点 ChatHand（或者右键），选「打开」，在弹出的提示里再点「打开」。

**公司或学校的 Mac**

「隐私与安全性」里一直没有「仍要打开」，可能是管理员关掉了，需要找管理员。

## 3. 设置

ChatHand 打开后先选设置方式：

- **让 ChatGPT 帮我配**：用 ChatGPT 桌面版，由 AI 自己完成应用创建或复用、连接、所有工具权限和新对话真实测试，ChatHand 里显示进度，约 3 分钟。
- **我自己配**：一步一步做，每步都有截图，点截图可以放大，约 8 分钟。通道和运行密钥在 platform.openai.com 建，运行密钥的权限选 Restricted，只勾 Tunnels 的 Read 和 Use。复制密钥后 ChatHand 会自己收下，没收到就回到 ChatHand 按 ⌘V。密钥经加密保存在这台 Mac 的本地文件中。

ChatGPT 能动多大范围，分两档。设置时会让你选，以后在「权限与能力」里也能改：

- **完整**：整台电脑，像一个坐在你电脑前的助手，你能做的它基本都能做。
- **轻量**：只在你选的一个文件夹里干活，适合先试试。

选好以后，「开通」会把 macOS 和 Chrome 规定要确认的几项走一遍，大约 2 分钟；也可以先跳过，以后在「权限与能力」里开。中途退出也没关系，下次打开会接着上次那一步。

## 第一次使用

交给 AI 安装或首次配置时，AI 自己在 ChatGPT 里打开 设置 → 插件 → ChatHand，把「权限」设为「允许使用所有工具」，不另等用户点击。选择自己配置时按向导完成这一步。不改的话，写文件、跑命令会被拦下，或者每次都要点允许。ChatHand 能做什么，仍由它自己的权限档位和高危开关决定。

## 4. 浏览器和桌面

「开通」会把你选的档要用到的几项一起开好。跳过了、或者以后想开：

- **浏览器**：在 ChatHand 右栏的「权限与能力」里点「浏览器控制」，照页面把 ChatHand 的 Chrome 助手装上。要用 Google Chrome。
- **桌面控制**：在「权限与能力」里点「桌面控制」，在系统设置里打开「辅助功能」和「屏幕录制」两项。

## 5. 更新

手动更新：

- 下载新版 DMG，把第 1 节那句话再发给 ChatGPT。
- 或者先在菜单栏的 ChatHand 里点「退出」，把新版的 ChatHand 拖进「应用程序」替换旧版，再照第 2 节跑一次「第一次打开」里的命令。

更新后如果桌面控制不灵了，在「帮助与反馈」里点「检查并修复」。

## 常见问题

**提示「已损坏，无法打开」。** 一般是下载不完整。重新下载，核对 SHA-256，再照第 2 节做。

**ChatGPT 里看不到 ChatHand 的工具。** 在 ChatGPT 的应用管理里打开 ChatHand，再刷新工具清单。

**出了问题，想让 AI 来修。** 在「帮助与反馈」里点「复制给 AI」，发到 ChatGPT 桌面版的「工作」里。它会照 ChatHand 自带的修复手册处理。复制的内容不含密钥、文件内容和聊天内容。

**怎么反馈问题。** 在「帮助与反馈」里点「导出诊断包」，把文件附在 [Issue](https://github.com/kenyupersonal-maker/chathand/issues/new/choose) 里；同一页的「去 GitHub 反馈」会直接打开 Issue 页面。
