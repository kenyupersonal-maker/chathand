# ChatHand 1.0.0-beta.4

下载：`ChatHand-1.0.0-beta.4-arm64.dmg`

SHA-256：随本地发布准备目录中的 SHA256SUMS 核对。

适用于 Apple 芯片 Mac、macOS 14 或更新。第一次打开要放行一次：双击安装盘里的「第一次打开」，复制命令，到「终端」粘贴、回车；交给 ChatGPT 装的话，它会处理。

## 用之前要准备的

- 一台 Apple 芯片（M 系列）的 Mac，macOS 14 或更新。
- 一个有权使用自定义 MCP 应用及所需工具权限的 ChatGPT 账号。Pro 账号曾通过读写实测；其他套餐及设备的可用性请以账号实际权限为准。团队或企业工作区可能需要管理员开启开发者模式和应用权限。
- ChatGPT 桌面版：想让 ChatGPT 帮你装、帮你配，就要装它；自己装、自己配也可以不装。
- 用你登录 ChatGPT 的账号登录 OpenAI 平台（platform.openai.com），在那里建通道和运行密钥。
- 要让 AI 操作浏览器时，需要 Google Chrome。
- 这台 Mac 要能连上 OpenAI。需要代理的地区，代理要一直开着。
- 不用装 Node 或 Homebrew，安装包里都带了。

## 本版本变化

- 版本 1.0.0-beta.4，构建号 1012。
- 安装盘的入口改成「让 ChatGPT 来装」。自己装改成先跑一行终端命令，系统设置放行和拖进「应用程序」留作备用。
- 首页任务进度会实时更新，断线后自动恢复或改用定时检查。
- 权限设置提供「完整」和「轻量」两档，浏览器与桌面控制各有独立开关。
- 管理员和开机自启放到「常用能力」，其它高危命令仍需单独确认。
- 浏览器支持批量步骤、全文阅读、查找与等待，桌面支持文字观察和批量操作，结果不明时先检查再继续。
- 首页例句可以打开 ChatGPT 并预填，运行密钥可在复制后自动接收。
- 外观支持浅色、深色和跟随系统，皮肤选择会保存在这台电脑上。
- 新增「工作量」页、任务用量和订阅档位估算，可隐藏显示或确认后清零。
- 应用支持在空闲时核对并安装更新，暂停、恢复和连接变更需要在 ChatHand 窗口里操作。
- 升级后旧备份只保留最近一份，其余移到同目录的「待清理」文件夹。
- 本版新增六个工具，升级后请在 ChatGPT 的 ChatHand 管理页点一次「刷新工具」。

## 已知限制

- 朋友试用版，只有 Apple 芯片 Mac 版本。
- 用自己的证书签名，还没做苹果公证；交给 ChatGPT 装的话，它会按随包说明处理放行。
- 账号登录、系统权限和 ChatGPT 里的授权，由 macOS 和 OpenAI 把关，其余由 ChatGPT 来做。
- 在 ChatGPT 里，先在输入框 @ 选 ChatHand 再发送。
