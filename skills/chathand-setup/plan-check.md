# 执行分工与入口
AI 完成安装、配置、平台 Copy 与助手交接、ChatGPT 插件创建或复用、连接、开发者模式、权限设成「允许使用所有工具」、刷新工具、新对话测试。安装提示词已含这些步骤，不再逐项问要不要继续。
只有这些交给用户：macOS 电脑密码或 Touch ID 框；账号登录密码和验证码；Chrome 自己的「添加扩展程序」确认；macOS「想访问其他 App 的数据」询问，以及系统设置里的辅助功能、屏幕录制等隐私开关；走 OpenAI 通道时，平台上建运行密钥的「Create secret key」这一下（只点创建，复制和交给 ChatHand 由 AI 做）。需用户创建或允许时，AI 把正确网页或 ChatGPT 切到最前、说明用途；用户完成后接着做。不能代输密码、绕过平台实际拒绝；报错留代码、先诊断。
平台拒绝 AI 操作时，先在用户看得见的浏览器把正确页面切到最前，再一句话说清哪个窗口、点哪里；不要把隐藏浏览器里的页面交给用户找。完成后核实际结果再继续。
要登录才能用的网页（ChatGPT 设置、Sites、OpenAI 平台），先在用户自己的浏览器里做，那边本来就登录着；控制不了用户的浏览器才用内置浏览器，先跟用户说一句「要在这里再登录一次」。使用用户已登录的账号；未登录只请用户登录。按实际插件、开发者模式和 Site 接口判断，不查账单、不拿旧截图猜。首次未选路线默认 OpenAI 通道；已选路线按用户选择，Site 缺能力见 runbook 第 2 节。不自行换路、编地址或假报完成。ChatHand 自身的权限档位和高危开关仍有效，不使用 sudo。
报错先说正在做什么、卡在哪、影响什么、下一步怎么继续，附错误码。原因未知就明确说未知；中止、Copy 或窗口失败不能猜成苹果认证、网络、剪贴板为空或用户错。
